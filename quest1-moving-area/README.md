# 퀘스트 1 — 인터넷 에이전트 리서치: 서울 가까운 이사 동네 비교

**질문**: 서울과 가까우면서 집값 부담이 상대적으로 덜하고, 생활하기 편한 곳은 어디일까?
**비교 대상**: 송파구 · 강동구 · 분당구 (기준: 집값 부담)

## 결론

| 동네 | 집값 부담 | 잘 맞는 사람 |
|---|---|---|
| 송파구 | 높음 | 예산보다 교통과 편의를 먼저 보는 사람 |
| 강동구 | 중간~높음 | 서울 안에서 비용과 편의를 함께 맞추려는 사람 |
| 분당구 | 중간~높음 | 넓고 정돈된 생활환경과 판교 접근을 원하는 사람 |

집값을 가장 중요하게 본다면 **강동구의 지하철역에서 조금 떨어진 단지**부터 살펴보는 것이 낫습니다.
