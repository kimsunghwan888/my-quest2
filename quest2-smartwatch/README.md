# 퀘스트 2 — 네이버 카페 여론 × 쿠팡 최저가 구매 결정 리포트

**정한 물건**: 건강측정용 스마트워치
**결론**: **삽니다** — 삼성 갤럭시워치8 40mm 블루투스, 쿠팡 406,430원

## 결론의 근거 3가지

1. 국내에서 혈압을 잴 수 있는 스마트워치는 사실상 갤럭시워치뿐 (삼성 헬스 모니터, 식약처 의료기기 허가). 갤럭시 휴대폰 사용 중이라 조건 충족.
2. 갤럭시워치8 별점 4.87점(리뷰 7,611개) vs 혈압 기능을 내세운 저가 워치 4.25~4.55점.
3. 단, 카페 실사용자 다수가 "워치는 보조, 정확한 혈압은 팔뚝 혈압계" — 전자혈압계 3~5만 원짜리를 같이 두는 조건.

## 조사 방법

- **네이버 카페**: 로그인 상태에서 통합검색 5개 검색어 조회, 글 14건의 본문·댓글을 직접 읽음.
- **광고글 제외**: `쿠팡 파트너스 활동의 일환으로 수수료를 제공받습니다` / `네이버 쇼핑커넥트 활동의 일환으로` 문구, 무관한 상품 키워드 억지 조합, "좋은 정보 감사합니다"만 달린 댓글 — 이 기준으로 7건을 광고로 판정해 제외.
- **쿠팡**: 상품 13종 조회. 화면의 별점은 0.5점 단위 반올림이라 쓰지 않고, 1~5점 리뷰 개수를 전부 세어 평균을 다시 계산함.

## 시행착오 (되풀이하지 않기 위해)

- AI가 조종하는 브라우저는 평소 쓰는 크롬과 **다른 창**이라 로그인이 따로 필요함.
- 쿠팡은 검색 URL로 바로 들어가면 403 차단됨 → 쿠팡 첫 화면을 연 뒤 검색창에 입력하는 방식으로 우회.
- 회원 전용 카페 글은 읽을 수 없어 제외함.
- 카페 검색을 최신순으로 하면 광고글이 훨씬 많이 섞임 → 정확도순이 나음.
