# 퀘스트 5 — My Midjourney (Network + AI)

**만든 것**: 한 줄만 적으면 정해둔 화풍으로 그림이 나오는 「한 줄 화방」
**열쇠(API 키) 필요 없음** — 무료 서비스만 씁니다.

## 미션 3가지를 어떻게 채웠나

| 미션 | 어디에 |
|---|---|
| 이미지 생성 스타일(화풍·분위기)을 미리 정해두기 | **화풍 8가지 단추** + **분위기 6가지 단추**. 각 화풍은 영어 프롬프트 조각(`en` + `tag`)을 갖고 있고, 「주문서 보기」에서 조립 결과를 확인·수정할 수 있음 |
| 프롬프트를 입력하면 그 스타일로 생성 | 한 줄 입력 → 영어로 자동 번역 → `화풍 + 주제 + 분위기 + 화풍 재강조` 순으로 조립 → 이미지 요청 |
| 생성된 이미지를 화면에 표시 | 전시장에 액자 카드로 걸림. 화풍·분위기·번역문·크기·씨앗값을 라벨로 표시. 저장 / 다시 그리기 / 내리기 가능 |

## 화풍 8가지

수채화 · 지브리풍 · 펜 드로잉 · 유화 · 수묵담채 · 옛 그림책 · 픽셀아트 · 사진
분위기: 없음 · 따뜻한 · 차분한 · 쓸쓸한 · 밝은 · 신비로운

## 쓰는 서비스 (모두 무료·열쇠 없음)

| 용도 | 주소 |
|---|---|
| 그림 생성 | `image.pollinations.ai` (flux 모델) |
| 한→영 번역 | `translate.googleapis.com` → 실패 시 `api.mymemory.translated.net` |

## 여는 방법

`my-midjourney.html` 을 두 번 눌러 열면 됩니다. 그림이 안 나오면 GitHub Pages 주소로 열어보세요 (브라우저가 파일에서의 인터넷 접속을 막는 경우가 있음).

**주의**: 클로드 아티팩트로 게시하면 그림이 안 보입니다. 아티팩트는 외부 이미지를 차단하기 때문입니다. 그래서 이 퀘스트는 아티팩트로 게시하지 않았습니다.

## 시행착오 (되풀이하지 않기 위해)

- **한글 프롬프트를 그대로 보내면 엉뚱한 그림이 나온다.** "눈 내리는 시골 기차역" → 여름 숲길, "만년필과 편지지" → 소녀 얼굴. 보내기 직전 영어로 번역해야 한다.
- **화풍을 문장 뒤에 붙이면 거의 무시된다.** `주제, 화풍` 순서로는 사진처럼만 나왔다. `화풍 of 주제 ... 화풍 태그` 로 **앞뒤에서 두 번 못박아야** 반영된다.
- **한꺼번에 여러 장 요청하면 429(사용량 초과)로 막힌다.** 한 장씩 줄 세우고 사이를 3초 띄웠다. 429면 9초·22초 간격으로 두 번 더 시도한다.
- **화면을 다시 그릴 때마다 이미지를 재요청하는 버그**가 있었다. 받은 그림을 `Map`에 기억해 두고 재사용해야 한다.
- `pollinations`는 **CORS를 열어둬서** `fetch`로 상태 코드를 읽을 수 있다. 덕분에 429를 정확히 구분하고, blob으로 받아 **진짜 파일 저장**도 된다.
- `text.pollinations.ai`(글 생성)는 이제 **402 유료**다. 번역에는 쓸 수 없다.
- 1024를 요청해도 무료 등급은 **768로 내려서** 준다. 라벨에는 실제 받은 크기를 표시한다.
