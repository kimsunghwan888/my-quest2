# 퀘스트 6 — 실시간 코인 시세 대시보드

**만든 것**: 「내 코인 시세판」 — CoinGecko에서 30초마다 시세를 받아 카드로 보여주는 대시보드
**열쇠(API 키) 필요 없음**

## 미션 3가지를 어떻게 채웠나

| 미션 | 어디에 |
|---|---|
| CoinGecko API로 실시간 가격·24시간 등락률 | `/api/v3/coins/markets?vs_currency=krw&ids=...&sparkline=true` — 가격·등락률에 더해 로고·시총순위·24시간 고저·7일 그래프까지 한 번에 받음 |
| 오르면 초록 / 내리면 빨강 카드 UI | 카드 왼쪽 띠, 등락률 배지, 7일 그래프가 모두 같은 색. **색만 쓰지 않고 ▲▼ 기호와 "24시간 오름/내림" 글자를 함께** 표시 (색을 구분하기 어려운 분도 읽을 수 있게) |
| 새로고침 / 자동 갱신 | 30초 자동 갱신 + 남은 시간 카운트다운 + 켜고 끄기 + 「지금 새로고침」 단추 |

## 더 넣은 것

- **코인 담기/빼기** — 한글 이름 단추 12개 + 영어 검색 (`/api/v3/search`), 목록은 브라우저에 저장
- **한글 이름표** — CoinGecko는 영어 이름만 주므로 33개 코인의 한글 이름을 직접 넣음
- **7일 그래프(스파크라인)** — 등락 방향에 따라 색이 바뀌고 끝점을 점으로 강조
- **값이 바뀐 카드만 반짝임** — 갱신 때 실제로 가격이 변한 카드만 초록/빨강으로 번쩍임
- **요약 줄** — 담은 개수, 오른 코인 수, 내린 코인 수, 가장 많이 오른 코인
- 다크 모드 지원

## 확인한 것

- 코인 7개 시세 정상 수신, 오름 1 / 내림 6 표시
- 프리셋으로 담기 (체인링크) → 카드 추가됨
- 영어 검색 `sui` → 「수이 (SUI)」 결과 → 담기 → 빼기 모두 정상
- 자동 갱신 카운트다운 감소, 끄면 「꺼짐」 표시

## 시행착오 (되풀이하지 않기 위해)

- **한글로는 코인을 검색할 수 없다.** `/search?query=도지` 는 빈 결과. 그래서 한글 이름표를 코드에 직접 넣고, 검색은 영어로 안내한다.
- `/simple/price` 대신 **`/coins/markets`** 를 쓰면 로고·순위·고저·7일 그래프까지 한 번에 온다. 요청 횟수를 아낄 수 있다.
- CoinGecko 무료 등급은 분당 요청 수가 제한된다. **30초 간격이면 분당 2회**라 여유롭다. 429가 오면 화면에 「붐빕니다」라고 알리고 다음 주기를 기다린다.
- 색만으로 오름/내림을 나타내면 안 된다. **▲▼ 기호와 글자를 반드시 함께** 넣었다.
